HOW IT WORKS

如何使用

  1. 先逐页浏览两家签发机构的完整账单样张，定位账户信息、账期、应付金额、用量或读数、费用明细和付款区。
  2. 点击图片打开原图放大，并对照官方账单指南；样张里的展示数据不代表任何人的当前账户。
  3. 可选上传 PDF、图片或纯文本文件；浏览器本地提取文字，与参考姓名、地址和可接受时效作简单比较。扫描件 OCR 可选英文或简体中文。
  4. 真实账单请通过自行找到的签发方官方渠道核验；此演示不会查询外部记录，也不判断真伪。
FAQ

关于地址证明本地演示与官方账单样张

这些是某位真实用户正在使用的账单吗？

不是。它们是签发机构公开发布的完整账单样张，含展示数据，便于认识字段结构；不对应任何用户的私人账单或当前账户。

官方样图会被修改吗？

不会。Con Edison 与 NYC DEP 四页官方公开样图原样展示，不重绘、不裁剪、不加标记；页面链接到两家机构的账单指南。

只看版式能判断真伪吗？

不能。真实账单的版式和字段会变化，仿造文件也可能模仿外观。需要核实实际记录时，应从你独立找到的官方渠道确认。

本地演示会给出正式核验结论吗？

不会。它只在当前浏览器内提取可读文字，与用户提供的参考值作字符串比较，并提示一些基础文件信号；不查询签发方、银行、政府、信用机构或第三方登记信息，也不判断文件真伪或居住资格。

我的文件会上传或保存吗？

不会。选择的文件和参考信息只在当前浏览器内存中处理，不发送到核验 API 或保存到 ChainSeek。OCR 引擎和语言模型按需从 ChainSeek 同源静态资源加载；应用不会把 OCR 语言模型保存到浏览器存储中。请只处理你有权查看的文件。

支持哪些文件和语言？

支持 PDF、PNG、JPEG、WebP 和纯文本；单个文件最大 15 MB，纯文本最大 2 MB，PDF 最多 8 页。PDF 文字层可直接读取；图片和扫描页可在本机使用英文或简体中文 OCR。识别不完整时需人工查看原件。
